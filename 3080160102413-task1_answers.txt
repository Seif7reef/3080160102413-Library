-- Question 1: How much is each member borrowing?
- SQL Query Used:
  SELECT m.member_id, m.first_name, m.last_name, COUNT(c.checkout_id) AS total_checkouts
  FROM members m
  LEFT JOIN checkouts c ON m.member_id = c.member_id
  GROUP BY m.member_id, m.first_name, m.last_name;
- Finding: Calculated the total checkouts per registered member. Using a LEFT JOIN ensured that members with zero checkouts were correctly included in the output.

--  Question 2: Which books match a chosen author pattern?
- SQL Query Used:
  SELECT book_id, title, author
  FROM books
  WHERE author LIKE 'Karim%';
- Finding: Filtered book records to return titles where the author's name starts with "Karim" (e.g., Karim Elwy).

--  Question 3: What are the most popular books?
- SQL Query Used:
  SELECT b.book_id, b.title, COUNT(c.checkout_id) AS checkout_count
  FROM books b
  JOIN checkouts c ON b.book_id = c.book_id
  GROUP BY b.book_id, b.title
  ORDER BY checkout_count DESC
  LIMIT 5;
- Finding: Identified the top 5 most borrowed books across the library network, led by "The Silver Kite" and "Fossils and Fireflies".

--  Question 4: Who are the most active readers?
- SQL Query Used:
  SELECT m.member_id, m.first_name, m.last_name, COUNT(c.checkout_id) AS books_borrowed
  FROM members m
  JOIN checkouts c ON m.member_id = c.member_id
  GROUP BY m.member_id, m.first_name, m.last_name
  ORDER BY books_borrowed DESC
  LIMIT 10;
- Finding: Extracted the top 10 members with the highest volume of total borrowing activity.

--  Question 5: What does a neighborhood's activity look like further back in time?
- SQL Query Used:
  SELECT c.checkout_id, m.member_id, m.first_name, m.last_name, m.neighborhood, c.checkout_date
  FROM checkouts c
  JOIN members m ON c.member_id = m.member_id
  WHERE TRIM(LOWER(m.neighborhood)) = 'maadi'
  ORDER BY c.checkout_date DESC
  LIMIT 100 OFFSET 10;
- Finding: Retrieved historic borrowing transactions for the 'Maadi' neighborhood, skipping the 10 most recent entries using OFFSET to view older borrowing activity.
